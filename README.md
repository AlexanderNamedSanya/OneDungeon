# OneDungeon

Единый список подземелий The Elder Scrolls Online: обычная и ветеранская сложности в одной строке, задания, обеты и достижения Clear, Hard Mode и Trifecta.

Автор: **oneDOK**. Версия в манифесте: **1.0**. ESO API: **101051**. Интерфейс: клавиатура/мышь.

## Установка

Скачайте репозиторий через **Code → Download ZIP** и скопируйте папку `OneDungeon` в `Documents/Elder Scrolls Online/live/AddOns/`. Включите аддон и выполните `/reloadui`. Внешние библиотеки не требуются.

Подробнее: [README аддона](OneDungeon/README.md).
